# 테스트 이미지
수업 시간에 제공받은 표준 테스트 이미지를 사용한다.
저작권이 불명확한 자료라 레포에는 포함하지 않으며 로컬 `images/` 폴더에 두고 사용한다.

## 파일 형식
모두 헤더 없는 8비트 그레이스케일 raw 파일 (픽셀 1개 = 1바이트)

| 파일 | 해상도 | 크기 |
|---|---|---|
| `*.512` (boat, lena 등) | 512 × 512 | 262,144 B |
| `*.256` (cman, face) | 256 × 256 | 65,536 B |

## 결과 이미지 규칙
- 인물 이미지(lena, barbara)의 처리 결과는 레포에 올리지 않는다
- 결과 캡처는 풍경·사물 이미지(boat, bridge, pepper 등)로만 남긴다
